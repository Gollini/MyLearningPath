# My Learning Path

This repository documents my progress through foundational topics in computing, programming, and machine learning. I am sharing it publicly in the hope that the notes, examples, and exercises may also be useful to other learners.

## About this repository

Most of the material is developed in Jupyter notebooks. My goal is to understand each topic by working through it directly: writing the code by hand, experimenting with the underlying ideas, and recording what I learn along the way.

The work is created with minimal AI assistance. The emphasis is on building my own understanding rather than generating finished solutions.

## Topics

The repository is a work in progress and will grow as I continue learning. Current material includes:

- **Operations** — experiments with operations and their cost.

## Using the notebooks

Clone the repository and open the notebooks with JupyterLab, Jupyter Notebook, or another compatible editor:

```bash
git clone <repository-url>
cd MyLearningPath
jupyter lab
```

Dependencies may vary between notebooks and will be documented as the repository develops.

## A note for readers

These notebooks are learning notes, not polished tutorials or production-ready implementations. They may contain incomplete sections, evolving explanations, or mistakes. If you find something useful, unclear, or incorrect, feedback and suggestions are welcome.
